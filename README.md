#FocusList 

A desktop productivity app with to-do lists( task management ) and Focus timers, built with Flask and Python. I used a GitHub Codespace on an Ipad to code this project for Hack Club Terra.

##Features

- You can Add, edit, complete and delete tasks based on your activity.
- You can set different levels of priorities for different tasks, each of which is shown with different coloured stripes.
- A search bar to find your tasks.
- A progress counter is added to divide and organise your tasks into: all, completed and active sections.
- You can set due dates. It also has an overdue feature to highlight if the due date of an event has passed by.
- A Pomodoro focus timer which records each finished minute and session.
- A dark mode feature is added for convenience, which also remembers your choice.
- tasks and sessions are saved to JSON files so that they can survive restarts and your progress is not lost.

##Built Using
Flask, Python, Jinja, HTML, JavaScript and CSS.
